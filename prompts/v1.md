# jobq — v1 (single prompt, low give-away)

First run `cp ../../README.md ./README.md && cp ../../../WOLF-NOTES.md ./WOLF-NOTES.md`,
then read both files fully before writing any code. `WOLF-NOTES.md` maps the toolchain
and the language as installed here; when the compiler disagrees with your memory, the
compiler is right.

You are a systems programmer writing **wolf**. Your workspace is the current directory,
one wolf module with exactly one `main`. Build the complete `jobq` tool exactly as
`README.md` specifies. There is **no starter code**.

## What to deliver

Everything in README §3 to the standard of §7.2: the layout and the job file (FR-1,
FR-2), the runner with captured output and leases (FR-3), exactly-once under racing
runners (FR-4), lease expiry and retries (FR-5), `ls`/`show`/`retry`/`stats` (FR-6 to
FR-8), robustness to malformed files (FR-9), the TERM behaviour or the named gap
(FR-10), the scale bar (FR-11), exit statuses (FR-12).

## Build & test

- `wolf build main.lu -o jobq` warning-free; `wolf fmt --check *.lu` clean.
- `wolf test .` covers the `-f` quoting rule, the job file round trip, and two in-process
  claimers over a temp directory (exactly one wins each job).
- `test.sh` (yours): every row of README §7.1 with the racing runners of R1 (four
  processes, 500 jobs, three repetitions) and the killed runner of R2/R3; `ok <row>` per
  line; non-zero on the first failure; a build error is a failure.

## How to work

README §8's order: the store first (every transition a rename or a `create_new`; read
`std/fs/fs.lu` for `create_new`, `move_file`, `entries`), then a serial runner, then
`-j N`, then the races. Read `std/process/process.lu`'s header before choosing how to
capture output and wait on several children; say in a comment what you chose. Run R1
after every change to the claim path.

When you believe you are done, run `wolf fmt --check *.lu`, `wolf test .` and `./test.sh`
once more and paste their last lines and exit statuses. Report any duplicate or lost job
rather than claiming completion.
